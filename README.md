# Destaque Local — Site institucional

Site institucional one-page da **Destaque Local | SITES**.

## Objetivo do MVP

Construir confiança institucional para leads que já receberam uma demo e querem entender quem é a Destaque Local, como o produto funciona, quais modelos existem e qual é a oferta vigente.

O institucional **não é tratado como novo canal de aquisição nesta fase**.

## Estado atual

Em desenvolvimento. Primeira etapa: **estrutura-base + Navbar + Hero** para avaliação visual do Founder antes de avançar para as demais seções.

## Direção visual

- dark-first;
- preto, branco e laranja da marca (`#ff4b00`);
- linguagem institucional limpa, forte e precisa;
- produto real como principal prova visual;
- sem estética genérica de agência/SaaS.

## Arquitetura aprovada

Hero → O que é a Destaque Local → VOLT/LUMEN → Como funciona → Oferta → Transparência → FAQ → CTA final → Footer.

## Stack

HTML + CSS + JavaScript estáticos.

GitHub é o source of truth. Publicação final prevista via Cloudflare Pages em `destaquelocal.com.br`.

## Descoberta

Durante o desenvolvimento/preview, o site permanece `noindex`. Na publicação definitiva do domínio institucional, o bloqueio deverá ser removido e o SEO técnico finalizado.
